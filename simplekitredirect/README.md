# Simple Kit Redirect

Send posts and pages to a new address, configured individually in the WordPress editor.

## Highlights

- Easily redirect access to a page or post to any URL you choose.

## How the plugin works

After activating the plugin, your posts and pages will have a new setting that allows you to specify a redirect URL. Leave it blank (the default) to display the page or post itself.

## Frequently asked questions

**What happens to parameters sent in the URL of the original page?**

If the redirect URL you specify contains its own parameters, those will be used. If the specified redirect URL does not include any "GET" parameters, those that were passed to the original address will be forwarded to it.
