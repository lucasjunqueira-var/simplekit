# Simple Kit Downloads

Manage file downloads on your website, with access counters and version management.

## Highlights

- Create as many file downloads as you want.
- Register multiple versions of the same file and allow independent downloads, or always download the most recent one.
- Track download statistics for your files by version and export information including the date and time of file access.

## How the plugin works

Start by configuring the global display of your download buttons, including their graphic and text properties.

[IMAGEM]

Create a download record.

[]

Add the various versions of your file, numbering them. You can use three numbering patterns: #, #.#, or #.#.# (such as "25", "25.2", or "25.0.15").

[]

Add the corresponding block to your post or page, indicating the download to be performed and the version. You can also adjust the button's visual properties. When clicked, the button starts the file download and records the moment the file is accessed.

[]


You can track and export your file's download statistics both globally and by version.
