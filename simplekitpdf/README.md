# Simple Kit PDF

Use this plugin to easily and quickly display PDFs on your pages and posts.

## Highlights

- Quick import of PDFs using the block editor.
- Display customization.

## How the plugin works

On your page or post, include the PDF importer block.

<img width="1920" height="913" alt="pdf" src="https://github.com/user-attachments/assets/3988249d-1ac0-462a-9ccd-f523fbe03ff8" />

Select the file to display from your media folder or specify the URL of a PDF file hosted on your website. After that, make some adjustments:
1. What is the display height? A fixed size? The height of the first page? The size of the entire PDF content?
2. Should the PDF viewer toolbar appear, with pagination, zoom, and other tools?
3. If the toolbar is displayed, include a button to download the PDF?
